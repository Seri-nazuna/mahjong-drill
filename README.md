# 麻雀 点数計算ドリル

麻雀の点数を答える練習ができるツールです。翻と符から答えるモードと、牌姿（手牌）から答えるモードがあります。
間違えたときは、どこで間違えたかを分類して記録します。

公開ページ：https://seri-nazuna.github.io/mahjong-drill/

## 機能

### 翻・符から

- **ランダム出題**：実際の対局で出やすい翻・符ほど多く出題します
- **答え合わせ**：正誤と正解の点数を表示します
- **間違いの分類**：不正解のとき、入力された点数から間違え方を判定します
  - 100点の切り上げ
  - 満貫・上限の判定
  - 親と子の取り違え
  - ツモの支払い
  - 翻による倍々
- **苦手を優先モード**：直近50問で間違いが一番多い分類に合わせた問題を優先して出題します
- **成績の保存**：正解率・連続正解・直近50問の間違いの内訳をブラウザに保存します
- **切り上げ満貫の切り替え**：30符4翻などを満貫として扱うかを選べます

### 牌姿から

- **手牌からの出題**：場風・自風・ドラ表示牌・リーチの有無と手牌を見て、点数を答えます。鳴き（チー・ポン・カン）のある手も出ます
- **答え合わせ**：正解の点数と、成立している役・翻数・符の内訳を表示します
- **間違いの分類**：役・翻の数え違い、符の数え違い、点数の計算の3つに分けて記録します
- **成績**：翻・符からのモードとは別に記録します

判定する役は次のとおりです。これ以外の役（役満や、一発・海底などの偶然役）は扱いません。赤ドラ・裏ドラもありません。

- 1翻：リーチ、門前清自摸和、断么九、平和、一盃口、役牌（三元牌・自風・場風）
- 2翻：三色同順、一気通貫、混全帯么九、対々和、三暗刻、三槓子、三色同刻、小三元、混老頭、七対子
- 3翻：純全帯么九、二盃口、混一色
- 6翻：清一色
- ドラ

三色同順・一気通貫・混全帯么九・純全帯么九・混一色・清一色は、鳴くと1翻下がります。

13翻以上は数え役満として扱います。本場・供託は扱いません。
