# 麻雀 点数計算ドリル

翻・符・親子・ツモロンの条件から点数を答える練習ツールです。
答え合わせのたびに**どこで間違えたか**を分類して記録し、自分の苦手を見つけられるようにしました。

公開ページ：https://seri-nazuna.github.io/mahjong-drill/

## 作った経緯

以前、翻と符を入れると点数と計算過程が表示される [麻雀 点数計算機](https://seri-nazuna.github.io/mahjong-score/) を作りました。
麻雀を始めたばかりの友人にとって、点数計算が一番の壁になっていたためです。

計算機を使ってもらう中で、答えを出す道具だけでは、本人が計算できるようになるまでには距離があると感じました。
そこで今回は、自分で答えを出す練習ができ、さらに間違え方から苦手が分かるツールを作りました。

## 機能

- **ランダム出題**：実際の対局で出やすい翻・符ほど多く出題します。20符ロンなど、ありえない組み合わせは出ません
- **答え合わせと計算手順の表示**：正解・不正解にかかわらず、基礎点から支払い額までの手順を表示します
- **つまずきの分類**：不正解のとき、入力された数字がどの間違い方で出る値かを照らし合わせ、次のどれに当たるかを判定します
  - 100点の切り上げ忘れ
  - 満貫・上限の判定ミス
  - 親と子の取り違え
  - ツモの支払いの取り違え
  - 翻による倍々の数え違い
- **苦手を優先モード**：記録が一番多い苦手に合わせた問題を優先して出題します（例：切り上げが苦手なら、切り上げが必要な問題を出す）
- **成績の保存**：正解率・連続正解・つまずきの内訳をブラウザに保存します
- **切り上げ満貫の切り替え**：30符4翻などを満貫として扱うかどうかを選べます

本場・供託は扱いません。

## 設計で考えたこと

### 間違いの分類方法

正解・不正解だけでは、何を直せばよいかが分かりません。
塾講師のアルバイトで、生徒の点数が伸びない原因は単元そのものより手前の知識の抜けにあることが多いと感じていたため、ここを一番大事にしました。

方法としては、よくある間違い方ごとに「その間違いをした場合に出る答え」をプログラムで計算し、入力された数字と一致するものを探しています。
例えば30符4翻の子のロンで 7680 と答えた場合、100点への切り上げをしなかった計算と一致するので「100点の切り上げ」に分類します。
どれにも当てはまらない場合は「その他」とし、無理に分類しないようにしました。

### 計算方法

前作と同じく、点数表を丸ごと持つのではなく `基礎点 = 符 × 2^(2+翻)` の式で計算しています。
式で計算することで、計算手順の表示や、間違った計算の再現がしやすくなるためです。

## 制作について
